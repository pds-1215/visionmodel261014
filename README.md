# 제조 품질 현황 대시보드 (Vision Inspection PoC)

AI 비전검사 모델 도입 전에, 데이터 흐름과 대시보드 구성을 테스트하기 위한 아주 심플한 Streamlit 웹 앱입니다.

## 🚀 로컬 실행 방법
1. 저장소 클론: `git clone [이 레포지토리 주소]`
2. 폴더 이동: `cd my_vision_dashboard`
3. 패키지 설치: `pip install -r requirements.txt`
4. 앱 실행: `streamlit run app.py`

## ☁️ Streamlit Community Cloud 배포 방법
1. 코드를 본인의 GitHub 레포지토리에 푸시(Push)합니다.
2. [Streamlit Community Cloud](https://share.streamlit.io/)에 접속하여 로그인합니다.
3. **'New app'** 버튼을 클릭합니다.
4. 방금 만든 GitHub 레포지토리, 브랜치(main), 그리고 메인 파일 경로(`app.py`)를 선택합니다.
5. **'Deploy'** 버튼을 누르면 끝! 1~2분 뒤에 나만의 대시보드 URL이 생성됩니다.
